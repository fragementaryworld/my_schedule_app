# 工作生活

本机运行的个人计划管理工具，使用 Node.js 原生模块，无需安装第三方依赖。

## 启动

已在 Node.js 24 环境验证。在项目目录执行 `npm start`，或双击 `启动.bat`，然后打开 <http://localhost:4321/>。

数据保存在 `data/data.json`，自动备份为 `data/data.json.bak`。请勿同时用多个服务写同一份数据；如检测到外部修改，保存会报错并保留磁盘数据，请重启后继续。

## 保存与结束

右上角「保存」会提交当前内容和预计用时等编辑，再保存到磁盘。

「保存并结束服务」确认后会提交待保存的编辑、等待进行中的写入、保存数据并释放服务端口。成功后页面显示结束提示，可以关闭浏览器。保存失败时服务继续运行，页面显示错误；处理后可以重试。

重新使用时再次启动并刷新页面。结束按钮只关闭本项目服务，浏览器页面会保留。

## 今日计划

「今日计划」默认展示周视图，可切换月视图。点击日历中的日期，下方共用的日期看板同步显示当天安排、当天截止、持续任务和已完成，任务平铺展示，所属清单作为辅助提示。已完成、持续任务和项目候选任务默认折叠。截止任务点击「加入当天」后转入当天安排，项目的起止日期保持原样；未设置截止日期的项目任务也可加入当天。

任务只通过「所属清单」选择收集箱、工作事务、生活事务或具体项目，不再填写事务标签和项目分类。新任务默认放入收集箱，旧的无项目任务兼容到工作事务。灵感转为任务时也使用同一选择，短期专题统一作为项目。历史来源、分类、标签数据保留。

日历和日期看板共用搜索与清单筛选，任务属性只通过「所属清单」确定存放位置，不再提供任务来源属性。历史来源数据保留用于兼容旧任务的归属。新增任务使用所选日期；切换视图保留所选日期，翻页时看板同步切换。一个项目任务目前保存一个计划日期，再次加入其他日期会调整它的安排；拖动日历中的「当天安排」只改计划日期。

## 测试

运行 `npm test`。测试使用独立临时数据，不依赖个人数据。

隔离运行示例（PowerShell）：

```powershell
$env:DATA_FILE = "$env:TEMP\schedule-preview\data.json"
$env:PORT = '4322'
$env:NO_BROWSER = '1'
npm start
```
